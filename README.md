# Bamboo Project 2

A beautiful project that creates an app on Windows that shows the images and steps required to make a fertiliser cup out of bamboo with a stake that goes in the ground. 

## Dedication

In the name of God, The Most Gracious, The Most Merciful.

## Tauri + GitHub Actions

This project is a Tauri built app for Windows, built using GitHub Actions because I don't have either Windows or a virtual machine with Windows.

## File Structure

The project had an html file, a single css file, and a javascript file before I built it with Tauri.
